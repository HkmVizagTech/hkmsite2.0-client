# Bengali glossary — harekrishnavizag.org

Style: warm, respectful, simple everyday Bengali (চলিত ভাষা, not সাধু ভাষা).
Address the reader as আপনি (করুন / দিন / দেখুন). Keep buttons, menu items,
labels and headings as short as possible — the site is mostly read on phones.

## Never translate / keep as is
- Placeholders: `{amount}`, `{name}`, `{date}`, `{time}` …
- Amounts and numbers (Western digits): `₹2,000`, `Rs. 100`, `80G`, `PAN`, phone numbers.
- UPI ID, email, URLs, `IFSC`, `NEFT / RTGS`, `A/c`.
- PhonePe, Google Pay, GPay, Paytm, WhatsApp, Razorpay, UPI, YouTube, Google Maps, Matchless Gifts.

# Marathi glossary — harekrishnavizag.org

Use these consistently. Style: warm, respectful, simple everyday Marathi (not
heavy literary). Address the reader respectfully (तुम्ही / करा forms).
Mobile-first: keep buttons, menu items and labels as short as the English.

## Never translate / keep as is
- Amounts and numbers: `₹2,000`, `Rs. 100`, `80G`, `PAN`, `IFSC`, `NEFT / RTGS`, phone numbers, digits in dates.
- Placeholders: `{amount}`, `{name}`, `{n}` etc.
- UPI ID, email, URLs, "Matchless Gifts" (shop brand).
- "PhonePe", "Google Pay", "GPay", "Paytm", "WhatsApp", "Razorpay", "UPI", "QR", "YouTube", "Google Maps", "CSR", "HKMI", "IIM".

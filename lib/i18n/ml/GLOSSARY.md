# Malayalam glossary — harekrishnavizag.org

Use these consistently. Style: warm, respectful, simple everyday Malayalam
(not heavy literary). Address the reader respectfully (താങ്കൾ / polite
imperative "-ൂ" for buttons, e.g. സംഭാവന നൽകൂ). Mobile first: keep buttons,
menu items, labels and headings as short as possible.

## Never translate / keep as is
- Amounts and numbers: `₹2,000`, `80G`, `PAN`, phone numbers, dates in digits.
- Placeholders like `{amount}`, `{name}`.
- UPI ID, email, URLs, brand names: PhonePe, Google Pay, GPay, Paytm, BHIM, WhatsApp, Razorpay, UPI.
